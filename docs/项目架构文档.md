# SkyGuard-UAV-Defense 项目架构文档

## 项目概述

SkyGuard-UAV-Defense 是一个完整的无人机智能安全研究和对抗攻防演练平台，集成了对抗攻击、防御算法、仿真环境和可视化界面。项目采用前后端分离架构，为低空无人智能体的智能安全研究提供全面的技术支撑。

## 整体架构

```
SkyGuard-UAV-Defense/
├── frontend/          # React前端界面
├── backend/           # Python后端服务
├── airsim/           # AirSim仿真器集成
├── datasets/         # 数据集存储
├── docs/            # 项目文档
└── results/         # 实验结果
```

## 后端架构 (Backend)

### 技术栈
- **框架**: FastAPI + Celery
- **深度学习**: PyTorch + Ultralytics YOLO
- **仿真**: AirSim Python Client
- **任务队列**: Celery + Redis
- **配置管理**: YAML配置文件

### 目录结构

```
backend/
├── algorithms/           # 攻防算法实现
│   ├── attacks/         # 对抗攻击算法
│   └── defenses/        # 防御算法
├── config/              # 配置管理
├── datasets/            # 数据集管理
├── models/              # 模型存储
├── utils/               # 工具模块
├── airsim_task/         # AirSim仿真任务
├── results/             # 实验结果
└── API文件
```

### 核心API端点

#### 1. 主要API模块 (`/api/`)
| 方法 | 端点 | 功能描述 |
|------|------|----------|
| `GET` | `/api/ping` | API健康检查 |
| `POST` | `/api/model/test` | 模型性能测试 |
| `POST` | `/api/attack/run` | 对抗攻击执行 |
| `POST` | `/api/defense/run` | 防御策略应用 |
| `POST` | `/api/defense/train` | 对抗训练防御 |
| `GET` | `/api/task/{task_id}` | 任务状态查询 |

#### 2. 攻击信息API (`/api/attacks/`)
- `GET /api/attacks/` - 获取所有攻击算法
- `GET /api/attacks/{attack_id}` - 特定攻击详情

#### 3. 配置管理API (`/config/`)
- 模型配置管理 (`/config/models`)
- 数据集配置管理 (`/config/datasets`)
- 支持CRUD操作和路径查询

#### 4. 可视化API (`/visualization/`)
- `GET /visualization/results/{task_id}` - 可视化结果
- `GET /visualization/image/{task_id}/{image_path}` - 结果图像
- `GET /visualization/compare/{task_id}` - 对比可视化

#### 5. 进度监控API (`/progress/`)
- `WebSocket /progress/ws/{task_id}` - 实时进度监控
- `POST /progress/update/{task_id}` - 进度更新

#### 6. AirSim仿真API (`/airsim/`)
- `POST /airsim/drone/mission` - 启动无人机任务
- `GET /airsim/drone/mission/{task_id}/status` - 任务状态

### 支持的算法

#### 对抗攻击算法
1. **PGD (Projected Gradient Descent)** - 投影梯度下降攻击
2. **FGSM (Fast Gradient Sign Method)** - 快速梯度符号法
3. **C&W L2** - Carlini & Wagner L2攻击
4. **DPatch** - 补丁式攻击
5. **Brightness Attack** - 亮度干扰攻击
6. **Gaussian Noise** - 高斯噪声攻击
7. **Contrast Attack** - 对比度调整攻击
8. **DeepFool** - DeepFool攻击
9. **AdvPatch** - 通用补丁攻击
10. **Distortion Attack** - 图像扭曲攻击
11. **Scene Transition** - 场景跃变攻击

#### 防御算法
1. **PGD Training** - 基于PGD的对抗训练
2. **FGM Defense** - 快速梯度法防御
3. **YOPO** - You Only Propagate Once防御
4. **FreeLB** - 自由边界防御
5. **FreeAT** - 自由对抗训练
6. **预处理防御**: 高斯模糊、JPEG压缩、中值滤波等

### 异步任务系统
基于Celery的异步处理，支持：
- `test_model_task` - 模型性能评估
- `run_attack_task` - 对抗攻击执行
- `run_defense_task` - 防御策略应用
- `adv_defense_train_task` - 对抗训练
- `drone_mission_task` - AirSim无人机任务

### 数据集和模型
- **数据集**: VisDrone无人机视角目标检测数据集
- **模型**: YOLOv8s-VisDrone微调模型

## 前端架构 (Frontend)

### 技术栈
- **框架**: React 18.2.0 + Vite 6.3.5
- **路由**: React Router DOM 7.6.1  
- **样式**: TailwindCSS 3.4.17 + TailwindCSS Animate
- **UI组件库**: Radix UI + 自定义UI组件

## 部署说明

### 后端部署
1. 安装Python依赖: `pip install -r requirements.txt`
2. 启动Redis服务
3. 启动Celery Worker: `celery -A celery_app worker --loglevel=info`
4. 启动FastAPI服务: `uvicorn main:app --reload`

### 前端部署
1. 安装Node.js依赖: `npm install`
2. 开发环境启动: `npm run dev`
3. 生产环境构建: `npm run build`

### Docker部署
提供docker-compose.yml支持容器化部署。
